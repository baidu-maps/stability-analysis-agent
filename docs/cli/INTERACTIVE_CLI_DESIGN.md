# 交互式 CLI 设计方案（Claude 风格）

本文档定义 `sa-agent` 的交互式体验升级方案与落地细节，目标是在安装后直接输入 `sa-agent` 即可完成一次稳定性分析，同时保持原有参数化调用完全兼容。

## 设计目标

- 零参数可用：`sa-agent` 自动进入交互向导。
- 参数兼容：已有 `--crash-log/--library-dir/--code-root` 脚本调用行为保持不变。
- 失败即修复：缺配置或路径错误时提供就地修复分支，不让用户重头开始。
- 渐进披露：默认仅采集关键参数，高级选项按需展开。
- 会话记忆：保存最近一次成功输入，并支持 profile 复用。

## 模式判定规则

1. `sa-agent` 零参数 + TTY：进入交互模式（默认用户路径）。
2. `sa-agent run ...`：显式运行入口，行为与主命令一致。
3. 非 TTY 环境（CI/管道）：默认非交互模式；若强制 `--interactive` 则报错退出。
4. `config/profile` 子命令仅作为高级能力保留，不在主引导中提示。

## 交互流程

### Step 0：首屏（无阻塞检测）

- 进入交互后直接展示意图菜单，不在首屏自动执行环境检测（避免启动阶段 1～2 秒级阻塞）。
- 进入“配置大模型 / 配置 addr2line 工具”时，会先做对应检测并展示结论，无需单独“环境检测”入口。

### Step 1：意图菜单

- `1) 快速开始分析（推荐）`
- `5) 再次进行上一次分析`（仅在存在最近一次分析记录时显示）
- `2) 设置`
- `3) 帮助`
- `q) 退出`
- 选择交互支持上下键切换并回车确认（兼容数字键输入）。

“设置”二级菜单包含：

- 配置大模型（厂商 / 密钥 / 模型）
- 配置堆栈地址解析工具（addr2line / atos 等）
- 高级选项（手动编辑配置文件 / 调整 AI 推理模式 / 调整 Agent 执行流程）

“帮助”二级菜单包含（纯只读浏览，与“设置”按职责分离）：

- 全部命令参考（完整参数手册）
- 命令快速示例（最小可运行）

在“配置大模型 / 配置堆栈地址解析工具”的交互向导中：

- 关键选择项（如 **厂商**（对应配置中的 `active_provider` / `providers` 键）、目标平台）支持上下键选择；
- 同时提供“返回”选项，可回退到上一层菜单；
- 支持“自定义输入”以兼容未预置的 **厂商或配置标识** / 平台。
- **配置大模型**：进入后先展示「大模型配置检测」（是否可用、**当前启用厂商（active_provider）** / 模型）；若已可用会询问是否重新设置。需要配置/重配时默认直接进入「交互向导填写」；与扩展菜单并存时，通用路径为「**交互向导：选择厂商并填写密钥**」。
- **配置堆栈地址解析工具**：进入后先展示「符号化工具检测」（是否可用、已检测到哪些工具）；若已可用会询问是否重新设置。需要配置/重配时默认直接进入「交互向导填写」。向导内仅保留 **「自动获取（推荐）」** 与 **「手动设置符号化工具绝对路径」**：后者可输入 **可执行文件**（如 `.../llvm-addr2line`）或 **仅含该工具的目录**，保存时统一写入 `tool_paths`（可执行文件会取其父目录）。**不再**提供「从 shell 读取环境变量名并写入 `environment_vars`」的独立菜单；`environment_vars` 仍可由「自动获取」写入或用户在 JSON 中手编。
- **高级选项**：提供「手动编辑大模型配置文件 / 手动编辑堆栈地址解析配置文件 / 调整 AI 推理模式（direct/langchain/langgraph）/ 调整 Agent 执行流程（完整分析、仅生成提示词、仅解析+符号化、仅解析日志）」入口。手动面板提供「打开文件 / 我已完成，检查配置是否正确 / 查看示例或关键字段 / 返回」；打开或查看说明后会提示按回车再显示菜单，避免误以为无响应。macOS 无 `EDITOR` 时用 `open -t` 调系统默认文本编辑器。

### Step 2：预检修复

- 用户选择 `1) 快速开始分析` 后，再执行一次轻量状态检测（`_doctor_status`），用于后续 LLM 预检分支。
- 若当前流程需要符号化（`full` / `prompt_only` / `parse_only`），在检查「堆栈工具是否就绪」之前，会先**静默调用**与「设置 → 自动获取」相同的探测与写入逻辑（若有可写入的 `environment_vars` / `tool_paths`），以减少用户重复点「自动获取」；仍检测不到时再进入「配置堆栈地址解析工具」或「忽略并继续」分支。
- 若 LLM 未配置，直接进入“配置大模型”引导；未完成时可继续配置或返回上一级菜单。
- AI 模式开关不再在“快速开始分析”主路径弹窗选择，统一放入“高级选项”。
- 解析范围（完整分析/仅解析+符号化/仅解析日志）统一放入“高级选项”。

### Step 3：路径向导

按顺序采集并即时校验：

1. 崩溃日志路径（必填，必须为文件）
2. 库目录（可空）
3. 代码目录（可多个，英文逗号分隔）

### Step 4：执行计划与自动执行

- 显示 4 阶段执行计划：
  - 解析日志
  - 符号化
  - 代码提取
  - AI 推理（或跳过 AI）
- 显示“用户显式设置参数”的参数摘要（避免默认值噪音）。
- 不再二次确认，展示后立即执行。
- 执行前提示：运行中可按 `Ctrl+C` 终止当前任务。
- 引擎调整不再出现在该步骤，统一放入“设置 → 高级选项”以简化主流程。

### Step 4.5：最近日志一键复跑（隐藏王牌功能）

- 当存在 `last_run.crash_log` 时，菜单显示 `5) 再次进行上一次分析`。
- 选择后会复用最近一次参数（日志/库目录/代码目录/engine/scope）并做轻校验。
- 若日志文件丢失则回退主菜单；若库目录/代码目录缺失则提示并自动忽略无效项。
- 提供快速确认：回车立即重跑，`e` 进入编辑，`q` 取消。

### Step 5：会话记忆（默认无感）

- 默认只记录最近一次成功输入（`last_run`），用于下次自动预填。
- 不在主引导流程中暴露 profile 概念，减少用户心智负担。
- profile 能力作为高级功能保留在子命令层，供进阶用户使用。

## 数据落盘

- 配置目录：`~/.config/stability-analysis-agent/`
- 会话状态：`~/.config/stability-analysis-agent/session_state.json`

## 高级附录（默认不暴露给普通用户）

profile 属于进阶能力，不在主引导流程中展示。仅在需要复用多套参数模板时使用：

- `sa-agent profile list`
- `sa-agent profile show <name>`
- `sa-agent profile use <name>`
- `sa-agent profile save <name>`（从 last_run 生成）
- `sa-agent profile delete <name>`

## 验收标准

- 零参数运行可完成一次完整分析或清晰退出。
- 无 LLM 配置时可在单会话内完成“配置/跳过 AI”分支。
- 参数模式与历史脚本保持兼容。
- `examples/crash_cases` 示例可通过交互或参数模式正常执行。
